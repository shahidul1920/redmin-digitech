# Redmun Digital Technology Platform - Project Specifications

## Project Overview & Architecture
* **Frontend:** Next.js (version 16+)
* **Backend:** Headless WordPress (headless WP API integration)
* **Brand/Company Name:** Redmun Digitech
* **Color Palette / Theme:**
  * **Brand (Logo Red):** `#FF0000` — core identity color from the "Red" in RedMun logo
  * **Primary (Action Blue):** `#0057FF` — CTAs, links, interactive elements
  * **Dark:** `#0B1220` — from the "Mun." in the logo, used for text and dark backgrounds
  * **Light:** `#F7F9FC` — page backgrounds and light surfaces

## Page-by-Page Structure

### 1. Home Page
* **Hero Section:**
  * Large Headline: `"Enterprise Management Platform Built for Growing Businesses"`
  * Sub Heading: One-sentence explanation of the company.
  * Call to Action (CTA): `"Request Demo"` (button) and `"View Products"` (button/link).
  * Trusted By: Client logos and Partner logos.
  * Key Stats:
    * `250+` Projects Delivered
    * `35+` Business Clients
    * `7` Specialized Products
    * `99.9%` Uptime
* **Specialized Products Grid:**
  * Interactive grid/cards containing an Image, Title, 2-line Description, and a `"Learn More"` link.
  * Product cards to include:
    1. News Portal
    2. Company Profile
    3. General E-Commerce
    4. 1688 API Integrated China Sourcing Platform
    5. Shipping Management System
    6. Custom Branded E-Commerce Solution
    7. Restaurant Chain Management Platform
* **Industries We Serve:**
  * Media, Corporate, Import Business, Shipping, Restaurant, Retail, Manufacturing.
* **Why Choose Us (Checklist):**
  * Industry Specific, Secure Architecture, Fast Performance, SEO Ready, Mobile First, Scalable, ERP Ready, API Ready.
* **Featured Product:**
  * Rotates/displays one highlighted product (e.g., *1688 API Ecommerce*) and displays:
    * Problem
    * Solution
    * Features
    * Call to Action (CTA)
* **Development Process (Vertical Flow):**
  * Requirement &rarr; Planning &rarr; UI Design &rarr; Development &rarr; Testing &rarr; Launch &rarr; Support.
* **Portfolio Snippet:**
  * Image, Mockup, Industry, Button.
* **Testimonials:**
  * Video, Quote, Company Logo.
* **Technology Stack (Modernized):**
  * Next.js + Headless WordPress (overrides legacy Laravel, Vue, React, PHP, MySQL, Redis, Docker, Cloudflare, AWS stack details).
* **FAQ:**
  * 10 Questions.
* **Final CTA:**
  * `"Let's Build Your Next Digital Platform"`.

### 2. Products Page (Main Directory)
* **Structure:** Banner &rarr; Introduction &rarr; Product Grid &rarr; Comparison Table &rarr; FAQ &rarr; CTA.
